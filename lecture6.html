Lecture 6: CSS Box Model & Layout

Summary

The CSS box model describes how every HTML element is treated as a box. It includes content, padding, border and margin and is important for page layout.

Topics Covered

  • Content
  • Padding
  • Border
  • Margin
  • Width and Height
  • Display Property

Example

div { padding: 20px; margin: 10px; }
